Features

Queue glaze recipes and let Create Pottery Script run the full fire cycle with consistent ramp curves every time.

Kiln Temp Tuning

Dial in precise temperature profiles, hold times, and cool-downs, then save them as reusable presets for any clay body.

Symmetric Shape Snap

FAQ

Questions from the wheel

Quick answers about installing and running Create Pottery Script on Windows.

Is Create Pottery Script really free? +

Yes. It is fully free and open source. Download the latest Windows build from gitscore.cc, and the source is available for inspection and contribution in the pottery-script-hub repository.

Which Windows versions are supported? +

Create Pottery Script runs natively on Windows 10 and Windows 11, 64-bit. No extra runtime or dependencies are required beyond the installer.

How does the Lua export work? +

Every finished pottery pattern — shape, glaze, kiln profile, and timing — is serialized into a clean, commented Lua module. Files land directly in your pottery-script-hub workspace so you can commit them with your normal Git flow.

Can I test kiln runs without firing for real? +

Absolutely. Dry-Run Mode simulates the full glaze fire, symmetry snap, and Lua export in-memory so you can validate recipes and batch scripts before any real kiln time is used.
